# 烘焙坊 · 烤箱设备与面包批次

烘焙坊生产管理：管理烤箱设备、面包配方，并以看板方式排产烘焙工单（待烤 → 烘焙中 → 已出炉 → 已质检），质检完成后出货（门店 / 外卖）。

## 故障接管

烤箱置为「故障」后，可从两个入口发起接管：烤箱列表的「故障接管」按钮，或工单看板中故障炉卡片上的「接管」按钮（开始烘焙被故障拒绝时也会弹出「前往接管」）。

- 烤箱详情中列出该炉当前的待烤 / 烘焙中工单，逐张选择替代烤箱，一次可整批迁移多张；
- 替代烤箱必须空闲、容量不小于工单实际烤盘数，且不能同时接收第二张烘焙中工单；
- 待烤迁移后仍为待烤（低风险）；烘焙中迁移后保留烘焙中状态与原开始时间（高风险，界面明确区分）；
- 任一张不满足条件则整批不落库，提示定位到具体工单与原因；并发两批抢同一替代烤箱时只成功一批；
- 故障炉修复后，未迁移的工单仍保留并可再次接管，已迁移工单不能重复迁回。

接口：`GET /api/ovens/{id}/takeover-orders` 查看在炉工单；`POST /api/ovens/{id}/takeover` 提交整批迁移（`{items:[{orderId,targetOvenId}]}`）。

## 启停

```bash
sh start.sh     # 启动（后端 + 前端 + MySQL）
sh stop.sh      # 停止
```
